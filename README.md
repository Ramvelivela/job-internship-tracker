# Job & Internship Tracker

A simple web application to manage and track job and internship opportunities in one place.

## Features

- Add new jobs
- Edit job details
- Delete jobs with confirmation
- Add new internships
- Edit internship details
- Delete internships with confirmation
- Search jobs
- Search internships
- Display total jobs and internships
- Responsive user interface
- SQLite database for storing data

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2
